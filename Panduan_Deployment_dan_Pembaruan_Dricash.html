Jika direktori di server masih kosong atau Anda ingin melakukan instalasi ulang dari nol:

mkdir -p ~/domains/dricash.andrichadhea.my.id/public_html
cd ~/domains/dricash.andrichadhea.my.id/public_html

# Inisialisasi git dan tautkan ke repository GitHub
git init
git remote remove origin 2>/dev/null || true
git remote add origin https://github.com/Kizker/dricash.git
git fetch origin main && git reset --hard origin/main && git pull origin main

# Bersihkan berkas default bawaan hosting jika ada
rm -f default.php index.php.bak
2 Konfigurasi Environment (.env.production) & Deploy Script
# Salin template konfigurasi production ke .env
cp .env.production .env

# Berikan izin eksekusi script dan jalankan deployment
chmod +x deploy.sh
bash deploy.sh
ℹ️
File .env.production telah terkonfigurasi dengan kredensial database Hostinger MySQL (u141095167_dricash) dan domain production https://dricash.andrichadhea.my.id. Script deploy.sh akan otomatis menjalankan migrasi skema tabel awal.

5. Konfigurasi Web Server (.htaccess & Hostinger LiteSpeed)
Meneruskan seluruh trafik HTTPS domain dricash.andrichadhea.my.id ke front-controller Laravel (public/index.php):
A. Hostinger / Apache / LiteSpeed (File .htaccess di Root public_html):
<IfModule mod_rewrite.c>
    RewriteEngine On

    # 1. Paksa penggunaan koneksi aman HTTPS
    RewriteCond %{HTTPS} off
    RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

    # 2. Teruskan seluruh request publik ke dalam direktori /public
    RewriteCond %{REQUEST_URI} !^/public/
    RewriteRule ^(.*)$ public/$1 [L]
</IfModule>
B. VPS Nginx Native (Opsional - Jika Menggunakan Server VPS Dedicated):
server {
    listen 80; listen 443 ssl http2;
    server_name dricash.andrichadhea.my.id;
    root /home/u141095167/domains/dricash.andrichadhea.my.id/public_html/public;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
    }
}
6. Troubleshooting & Tips Penting
⚠️ Error 500 / Internal Server Error (Blank White Page): Pastikan izin direktori storage dan bootstrap/cache telah diatur ke mode tulis: chmod -R 775 storage bootstrap/cache. Periksa log detail permasalahan melalui file storage/logs/laravel.log.
⚠️ Database Access Denied (SQLSTATE[HY000] [1045]): Periksa konfigurasi DB_DATABASE, DB_USERNAME, dan DB_PASSWORD di file .env apakah sama persis dengan yang ada di panel MySQL Hostinger. Jalankan php artisan config:clear setelah mengedit berkas .env.
🔄 Tampilan Belum Berubah Setelah Deploy (Browser / Cloudflare Cache): Lakukan Hard Refresh di browser dengan menekan Ctrl + F5 (Windows) atau Cmd + Shift + R (Mac). Jika domain menggunakan Cloudflare Proxy, buka menu Caching → Configuration → Purge Everything.
📑 Akun Admin Bawaan & Hak Akses Panel: Gunakan kredensial admin default untuk login pertama kali: Email admin@dricash.app dan Password password. Dari dashboard admin, Anda dapat mengaktifkan/menangguhkan user serta menyetel kategori master.
