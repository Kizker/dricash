git commit -m "Update fitur atau perbaikan terbaru"
git push origin main
B Di Server Hostinger: Terapkan Pembaruan (1 Baris Perintah)
# 1. Login SSH ke Server Hostinger
ssh -p 65002 u141095167@46.202.138.88

# 2. Masuk ke direktori domain & jalankan deploy script (Docker atau Native)

bash deploy-docker.sh # Atau gunakan 'bash deploy.sh' untuk native PHP

Perintah bash deploy-docker.sh otomatis menarik kode terbaru dari GitHub, memicu build image container Docker (Nginx + PHP-FPM 8.2), mengeksekusi migrasi database MySQL secara aman di dalam container, dan merefresh container tanpa downtime.
2. Prosedur Pembaruan Manual (Jika Tanpa Script)
# Masuk ke direktori server
cd ~/domains/dricash.andrichadhea.my.id/public_html

# Ambil update terbaru dari GitHub
git fetch origin main && git reset --hard origin/main && git pull origin main

# Jalankan orkestrasi container Docker
docker compose up -d --build && docker compose exec -T app php artisan migrate --force

# Atur perizinan file & reverse proxy
chmod -R 755 . && chmod 644 .htaccess

3. Setup Awal / Pemulihan Server (Fresh Installation)
Jika direktori di server masih kosong atau Anda ingin melakukan instalasi ulang dari nol:
1 Kloning & Sinkronisasi Kode dari GitHub
# Buat dan masuk ke direktori domain di server
mkdir -p ~/domains/dricash.andrichadhea.my.id/public_html
cd ~/domains/dricash.andrichadhea.my.id/public_html

# Inisialisasi git dan tautkan ke repository GitHub
git init
git remote remove origin 2>/dev/null || true
git remote add origin https://github.com/Kizker/dricash.git
git fetch origin main && git reset --hard origin/main && git pull origin main

# Bersihkan berkas default bawaan hosting jika ada
rm -f default.php index.php.bak
2 Jalankan Deploy Script & Konfigurasi .htaccess
# Salin konfigurasi environment production
cp .env.production .env

# Berikan izin eksekusi script dan jalankan container Docker
chmod +x deploy.sh deploy-docker.sh
bash deploy-docker.sh
ℹ️
File .htaccess sudah otomatis disediakan di repositori untuk menangani reverse proxy Apache/LiteSpeed menuju container Dricash di port 8000 lengkap dengan dukungan WebSocket dan HTTPS.
4. Deployment Menggunakan Docker (Multi-Container Architecture)
Aplikasi ini berjalan dengan container terisolasi yang dihubungkan melalui internal bridge network dricash_net:
Container Name Service Engine Port Peran & Tanggung Jawab
dricash_app Laravel 11 + Nginx (PHP 8.2) 8000 Antarmuka Web SPA (Vue 3 + Inertia), REST API, alokasi kekayaan, dan auth.
dricash_db MySQL 8.0 (Opsional) 3306 Penyimpanan mandiri (opsional jika tidak memakai database Cloud Hostinger).
🐳 Opsi A: Jalankan dengan Docker Compose (Direkomendasikan)
# Bangun image dan jalankan container di background
docker compose up -d --build

# Cek status container & logs streaming
docker compose ps && docker compose logs -f
🚀
Frontend Vue 3 + Vite dan dependensi Composer dikompilasi menggunakan multi-stage build, menghasilkan image produksi yang mandiri, ringkas, dan berperforma tinggi tanpa membebani memori server.

5. Konfigurasi Reverse Proxy (.htaccess & Nginx)
Meneruskan seluruh trafik HTTPS domain dricash.andrichadhea.my.id ke container Dricash port 8000:
A. Hostinger / Apache / LiteSpeed (via .htaccess di public_html):
<IfModule mod_rewrite.c>
    RewriteEngine On

    # 1. Paksa penggunaan koneksi HTTPS aman
    RewriteCond %{HTTPS} off
    RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

    # 2. Reverse proxy ke Container Docker Dricash port 8000
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteRule ^(.*)$ http://127.0.0.1:8000/$1 [P,L]
</IfModule>
B. VPS Nginx Native (Jika Menggunakan Server VPS Dedicated):
server {
    listen 80; server_name dricash.andrichadhea.my.id;
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
6. Troubleshooting & Tips Penting
⚠️ Error 502 Bad Gateway / Connection Refused: Pastikan container sedang berjalan dengan mengecek docker compose ps. Jika container berhenti atau crash, jalankan docker compose logs -f app untuk menganalisis log container aplikasi.
⚠️ Database Access Denied (SQLSTATE[HY000] [1045]): Periksa konfigurasi DB_DATABASE, DB_USERNAME, dan DB_PASSWORD di file .env apakah sama persis dengan yang ada di panel MySQL Hostinger. Jalankan docker compose exec app php artisan config:clear.
🔄 Tampilan Belum Berubah Setelah Deploy (Browser / Cloudflare Cache): Lakukan Hard Refresh di browser dengan menekan Ctrl + F5 (Windows) atau Cmd + Shift + R (Mac). Jika domain menggunakan Cloudflare, buka menu Caching → Configuration → Purge Everything.
📑 Akun Admin Bawaan & Hak Akses Panel: Kredensial default admin: Email admin@dricash.app dan Password password. Gunakan akun ini untuk masuk ke dashboard admin guna mengelola user dan kategori master.
